# Семантическое ядро — Station One Cafe (Гомель)

Основа: **коммерческие** запросы (заказать / забронировать / услуга) + **нужные информационные** по адресу и маршруту.  
Город: **только Гомель** (и лат. *gomel*).

### Правила отбора
1. Без: бесплатно, бу, авито, своими руками, форум.  
2. Информационные — только адрес / как добраться / куда сходить (под визит).  
3. Без других городов.  
4. Без «атмосферных» без действия (свидание, с друзьями, вечер в кафе).

Частотности ориентировочные (ВЧ / СЧ / НЧ).
